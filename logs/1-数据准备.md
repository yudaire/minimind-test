
# 02 数据准备

## 目标
下载 MiniMind 训练数据集，确认数据完整性和存储位置。

## 数据信息

| 文件 | 大小 | 用途 |
| :--- | :--- | :--- |
| `pretrain_t2t_mini.jsonl` | 1.2G | 预训练（mini 版） |
| `sft_t2t_mini.jsonl` | 1.7G | SFT（mini 版） |

| `sft_t2t.jsonl` | 14G | SFT（完整版） |
| 其他（RL、DPO、LoRA 等） | 少量 | 后续阶段 |
| **总计** | **约 24GB** | |

## 命令

### 下载数据集
```bash
cd /root/autodl-tmp/minimind
modelscope download --dataset gongjy/minimind_dataset --local_dir ./dataset
```


### 验证下载结果
```bash
ls -lh /root/autodl-tmp/minimind/dataset
du -sh /root/autodl-tmp/minimind/dataset
df -h /root/autodl-tmp
```
