## 关键命令

### 下载数据集
```bash
cd /root/autodl-tmp/minimind
modelscope download --dataset gongjy/minimind_dataset --local_dir ./dataset
```

### 仅下载 mini 版（可选，节省时间）
```bash
modelscope download --dataset gongjy/minimind_dataset \
  --include "pretrain_t2t_mini.jsonl" "sft_t2t_mini.jsonl" \
  --local_dir ./dataset
```

### 验证下载结果
```bash
ls -lh /root/autodl-tmp/minimind/dataset
du -sh /root/autodl-tmp/minimind/dataset
df -h /root/autodl-tmp
```

## 问题与排查

### 问题 1：下载进度条卡住不动
**现象：** 终端进度条长时间不更新，疑似卡死。

**排查：**
1. 另开终端，运行 `ps aux | grep modelscope` 确认进程仍在。
2. 运行 `du -sh /root/autodl-tmp/minimind/dataset` 观察目录大小变化。
3. 确认系统盘未满（`df -h /root`）。

**结论：** 进度条不动但目录大小在涨，属于正常下载，非卡死。

**处理：** 等待下载完成，不中断、不重复启动下载。

---

### 问题 2：终端输出交错混乱
**现象：** 多个进度条同时刷新，终端显示重叠、错乱。

**原因：** 多个大文件并行下载，进度条刷新导致终端换行错位。

**结论：** 显示问题，不影响文件完整性。最终输出 `Successfully Downloaded` 确认下载成功。
