# 环境准备

## 目标
搭建训练 MiniMind 所需的环境：本地工具、远程 GPU 服务器、Python 依赖。

## 执行

### 本地准备
- 安装 Git
- 安装 VS Code
- 在 VS Code 中安装 `Remote - SSH` 扩展（Microsoft 出品）

### 租用 GPU
- 平台：AutoDL
- GPU：RTX 4090 / 24GB
- 数据盘：70GB
- 镜像：PyTorch 2.8.0 / Python 3.12 / CUDA 12.8 / Ubuntu 22.04

### 远程连接
用 VS Code 的 `Remote-SSH` 连接服务器，添加主机时输入 AutoDL 提供的登录指令。

### 验证环境
```bash
nvidia-smi
python --version
python -c "import torch; print('torch:', torch.__version__); print('cuda:', torch.cuda.is_available()); print('gpu:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'none')"
