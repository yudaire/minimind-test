
# 03 预训练

## 目标
使用预训练数据训练 MiniMind 基础模型，使其学习语言规律，为 SFT 提供基础权重。

## 训练配置

| 项目 | 配置 |
| :--- | :--- |
| 脚本 | `trainer/train_pretrain.py` |
| 数据 | `dataset/pretrain_t2t_mini.jsonl` |
| 可视化 | SwanLab（`--use_wandb`） |
| 总步数 | 约 39,695 步/轮 |
| 训练轮数 | 2 |
| 检查点目录 | `out/` |

## 关键命令

### 激活环境并启动训练
```bash
source /root/miniconda3/etc/profile.d/conda.sh
conda activate /root/autodl-tmp/minimind_env
cd /root/autodl-tmp/minimind/trainer
python train_pretrain.py --use_wandb
```

### 单卡运行（替代方式）
```bash
torchrun --nproc_per_node 1 train_pretrain.py
```
`--nproc_per_node 1` 表示单卡，多卡可改为 2 及以上。

### 查看检查点
```bash
ls -lh /root/autodl-tmp/minimind/out
```

### 保存命令历史
```bash
history | tail -200 > /root/autodl-tmp/minimind/terminal_history_2026-09-18.txt
```

## 实验现象

### Loss 曲线
- 持续下降，曲线平滑。
- 使用 SwanLab 实时监控。
- 初期下降快，后期逐渐趋缓。

### 学习率曲线
- 平滑下降，符合余弦退火调度。
- 初期大学习率快速下降 loss，后期小学习率稳定收敛。
- 下降规律：先 Warmup，再余弦衰减至接近 0。

### Epoch time
- 呈阶梯型下降。
- 第一个 epoch 最慢，后续 epoch 速度提升后趋于稳定。

### 训练进度
- 第一轮约 39,695 步。
- 第一轮完成后自动进入第二轮。
- 第二轮结束后训练停止。

## 问题与排查

### 问题 1：从根目录运行报错 `../model`
**报错：**
```
HFValidationError: Repo id must use alphanumeric chars... The name cannot start or end with '-' or '.': '../model'
```
**原因：** 脚本默认 tokenizer 路径为 `../model`。从 `minimind` 根目录运行时，`../model` 指向 `/root/autodl-tmp/model`，该目录不存在，transformers 将其误判为 HuggingFace 仓库名。

**解决：** 进入 `trainer` 目录后再运行：
```bash
cd /root/autodl-tmp/minimind/trainer
python train_pretrain.py --use_wandb
```
此时 `../model` 指向 `/root/autodl-tmp/minimind/model`，路径正确。

---

### 问题 2：忘记激活虚拟环境
**现象：** 推理时报 SciPy 错误，报错路径为 `/root/miniconda3/lib/python3.12/`（base 环境）。

**原因：** 新开终端未执行 `conda activate`，使用了系统默认 Python 3.12 环境。

**解决：** 每次新开终端先执行：
```bash
source /root/miniconda3/etc/profile.d/conda.sh
conda activate /root/autodl-tmp/minimind_env
```

---

### 问题 3：训练中终端断开
**现象：** 移动电脑时网络中断，VS Code 终端与服务器断开，无法看到实时输出。

**确认训练仍在运行：**
```bash
nvidia-smi
ps aux | grep train_pretrain | grep -v grep
```
- GPU 利用率高，显存被占用。
- 进程存在。
- SwanLab 曲线仍在更新。

**结论：** 训练进程未死，仅终端连接断开。

**后续建议：** 长时间训练使用 `tmux`，避免断连影响监控。

## 结果
- 预训练完成，共 2 个 epoch。
- 检查点保存在 `/root/autodl-tmp/minimind/out/`。
- 模型具备文本续写能力。
- 模型不具备对话能力（符合预训练阶段预期）。

## 分析

### 为什么预训练模型只会续写？
预训练任务为“根据前文预测下一个词”，模型学习的是语言规律和词序列概率分布，未接触“问题-回答”格式的数据。因此输入“中国的首都是”，模型会续写“北京，它是一个历史悠久的城市……”，而非简洁回答“北京”。

### 为什么学习率平滑下降？
使用余弦退火调度器。初期大学习率快速下降 loss，后期小学习率稳定收敛，避免在最优解附近震荡。

### 为什么 epoch time 阶梯下降？
第一个 epoch 从磁盘读取数据并 tokenize，后续 epoch 数据被操作系统或 DataLoader 缓存至内存，读取速度提升。数据集 24GB，内存 62GB，可全部缓存。
